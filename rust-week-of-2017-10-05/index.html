Rust week of 2017-10-05
Posted on 2017-10-13 :: Rust

Continuing with the work project, I replaced the interfaces library with pnet, a weird concoction of various network functionality in one ugly mess, but I did it because the order of the network interfaces it presents does not randomly change (the project is UI that presents various bits of info about the boxes that we sell, some of which is network-related), unlike is the case with interfaces. It is also comforting that the library has more users (one vs. eight at time of writing).
